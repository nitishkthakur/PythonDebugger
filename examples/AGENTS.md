# Example index

Read root guidance before working here.

| File | Purpose |
| --- | --- |
| `demo.py` | General debugging and inspection demonstration |
| `demo_mro.py` | Inheritance and method-resolution inspection demonstration |
| `demo_pandas.py` | Optional pandas/NumPy inspection demonstration |
| `demo_crash.py` | Uncaught-exception and post-mortem demonstration |

These files are debuggees, not runtime dependencies. Keep examples small and
offline. Optional packages may be used only where explicitly demonstrated; do
not add installs. Check a changed example by running it or the relevant debugger
interaction, allowing intended exceptions for crash demonstrations. Launch with
temporary settings for manual checks using the root guidance command. Keep this
index current and add local guidance before adding nested example folders.
